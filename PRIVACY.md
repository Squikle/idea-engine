# Privacy Policy — idea-engine

Effective: August 2, 2026

idea-engine is a personal tool with exactly one user: me, its author. It runs on my
own computer and helps me spot product trends for hobby projects.

## What it reads

Through official, read-only APIs the tool fetches publicly available data such as
trending search keywords, public posts, and public product listings from services
like Pinterest, Reddit, Hacker News, Bluesky, YouTube, and marketplaces.

## What it stores

Keyword texts, public post texts, and aggregate metrics (for example "this keyword
is growing this month") in a private database on my own machine. That's it.

## What it does NOT do

- It does not collect, store, or process personal data about any platform's users.
- It does not profile individuals or infer anything about specific people.
- It does not post, message, follow, or interact with anyone on any platform.
- It does not share, sell, or transfer any data to third parties.
- It has no website, no visitors, no cookies, no analytics, no advertising.

## Data removal

If a platform requires deletion of content copies (for example content a user
deleted at the source), the tool honors that through scheduled cleanup jobs.
